윤호채원 위젯 설치

아이폰 홈 화면·잠금 화면에 이번 달 예상 용돈과 확인 대기 건수를 보여줘요. 15~30분마다 저절로 새로 고쳐지고, 누르면 앱이 열려요.

1. Scriptable 앱 설치 (무료)

앱스토어에서 Scriptable 받기

2. 위젯 코드 복사

// 윤호, 채원이네 위젯 — Scriptable 앱에 이 글 전체를 붙여넣어요.
// ▼ 이 폰을 쓰는 사람: 아빠·엄마 폰은 "parent", 윤호 폰은 "yunho", 채원이 폰은 "chaewon"
const WHO = "parent";
// ▼ 앱 로그인 비밀번호 (비밀번호를 안 정했으면 "" 그대로 두기)
const PIN = "";
// ▼ 부모님 폰에서 내 이름 ("아빠" 또는 "엄마")
const NAME = "아빠";

// ---- 아래는 고치지 않아요. 위젯 본체를 인터넷에서 자동으로 받아 최신으로 유지해요. ----
const fm = module.filename.includes("Documents/iCloud") || module.filename.includes("Mobile Documents") ? FileManager.iCloud() : FileManager.local();
const dir = module.filename.slice(0, module.filename.lastIndexOf("/"));
const core = fm.joinPath(dir, "ycn-widget-core.js");
try {
  const r = new Request("https://friese8807.github.io/ycn-app/widget-core.js?t=" + Date.now());
  r.timeoutInterval = 15;
  const code = await r.loadString();
  if (code.includes("YCN_WIDGET")) fm.writeString(core, code);
} catch (e) {}
if (fm.isFileStoredIniCloud(core) && !fm.isFileDownloaded(core)) await fm.downloadFileFromiCloud(core);
await importModule("ycn-widget-core")({ who: WHO, pin: PIN, name: NAME });

3. Scriptable에 붙여넣기

  1. Scriptable을 열고 오른쪽 위 +를 눌러요.
  2. 빈 화면을 길게 눌러 붙여넣기 해요.
  3. 맨 위 세 줄만 이 폰에 맞게 고쳐요.
    • WHO: 부모님 폰은 "parent", 윤호 폰은 "yunho", 채원이 폰은 "chaewon"
    • PIN: 앱 로그인 비밀번호 (없으면 그대로)
    • NAME: "아빠" 또는 "엄마"
  4. 위쪽 제목을 눌러 이름을 윤호채원으로 바꾸고 완료를 눌러요.
  5. 한 번 눌러 실행해서 미리보기가 나오는지 확인해요.

4. 홈 화면에 위젯 추가

  1. 홈 화면 빈 곳을 길게 누르고 왼쪽 위 편집 → 위젯 추가를 눌러요.
  2. Scriptable을 찾아 크기를 골라 추가해요.
  3. 추가된 위젯을 길게 눌러 위젯 편집 → Script에서 윤호채원을 골라요.

크기별로 보이는 것

작게두 아이 예상 용돈과 확인 대기 건수
중간두 아이 나란히: 사진, 예상 용돈, 상점·벌점, 대기 건수, 정산 D-day
크게중간 내용 + 오늘 기록 수와 가장 최근 기록
잠금 화면“윤호 501,000 · 채원 40,000”처럼 한 줄 또는 두 줄

한 아이만 크게 보고 싶으면 위젯 편집의 Parameter 칸에 윤호 또는 채원을 적어요. 작은 위젯에 한 아이만 넣으면 오늘 기록과 최근 기록까지 보여요.

참고

  • 비밀번호는 이 폰의 Scriptable 안에만 저장돼요.
  • 인터넷이 안 될 때는 마지막으로 받은 내용을 빨간 “연결 안 됨” 표시와 함께 보여줘요.
  • 위젯 모양은 앞으로 고쳐도 다시 붙여넣을 필요 없이 자동으로 바뀌어요.
